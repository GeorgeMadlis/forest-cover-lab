# Specifications

This directory contains formal algorithm specifications for each phase of Forest Cover Lab.

## Files

| File | Phase | Status |
|---|---|---|
| `v1_forest_baseline.md` | v1 | Proposed |
| `v2_monthly_confirmation.md` | v2 | Proposed |
| `v3_weak_supervision_monthly.md` | v3 | Proposed |

## Rules

- Each spec must contain: formal definitions, inputs/outputs, masking rules, compositing logic, area computation policy, error modes, validation requirements, and what cannot be claimed scientifically.
- Specs must reference the relevant ADRs in `docs/adr/`.
- Specs must be updated alongside ADR changes.
