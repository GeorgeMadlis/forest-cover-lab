# Agent output requires reviewed promotion

Agent extraction and interpretation enter as candidates. Passing structural checks, a successful run or an evaluator agent cannot promote knowledge. Human review records an attributable decision and evidence basis. Disturbance candidates are not legal deforestation, confirmed forest state or causal loss labels. Hansen annual loss is not monthly ground truth.
