# Methodology Track

This track defines and records how knowledge is acquired in Forest Cover Lab.

**Principle:** P1 - Research Protocol and Evidence Capture (`governance/principles.md`)

## Inputs

None required. This track is the entry point for all other tracks.

## Outputs

- A declared search scope for every research activity
- `search_scopes.csv` — reusable search-scope records referenced by inventories
- `practitioner_sources.md` — a curated list of practitioner sources to monitor
- `research_guide.md` — the protocol for all knowledge acquisition

## Optional cross-track dependencies

This track informs all others but is not a prerequisite for any of them. Any track
may be entered independently; following this guide makes the entry more systematic.

---

## Files

| File | Purpose |
|---|---|
| `research_guide.md` | Protocol for finding, reading, and recording knowledge |
| `search_scopes.csv` | Search-scope registry used by publications, data sources, and code sources |
| `practitioner_sources.md` | Curated list of practitioner blogs and technical channels |

## Rules

- Every research activity (a literature search, a code search, a data source survey)
  must begin with a declared search scope.
- The scope is recorded in `search_scopes.csv` before searching begins, not reconstructed
  afterward.
- Blogs and technical reports are valid research inputs and must be classified as such
  in the relevant inventory, not silently mixed with peer-reviewed papers.
